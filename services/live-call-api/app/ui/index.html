How this score is calculated

      
    

    


      
Every number this dashboard shows can be traced back to something concrete — nothing here is a black box. This page shows the same pipeline the API actually runs, with today's real configuration pulled live from /v1/config.


      

        
      


      
The six pluggable signals — how each one actually computes its number

      


      
Step 1 — Fusion: weighted sum, renormalized

      

        
fused = Σ weight × score, over signals that didn't abstain

        
If a signal abstains (near-silent audio, no transcript, no enrolled voiceprint) it's dropped from the sum entirely and the remaining weights are rescaled to still add up to 100% — an abstained signal never silently drags the score toward zero just for having nothing to say.

      


      
Step 2 — Smoothing across time (EMA)

      

        
smoothed = α × raw_this_window + (1 − α) × smoothed_previous_window

        
Keeps the score from jumping wildly window to window — a higher α reacts faster to new evidence, a lower α is steadier.
