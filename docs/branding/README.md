# Satya-Vani branding assets

The mark: a calm voice waveform inside an open ring, breaking into red at
the point a cloned voice is caught — meant to read literally, not just
decoratively.

- `satya-vani-icon.svg` / `.png` — mark only, for favicons/app icons.
- `satya-vani-logo-light.svg` / `.png` — full wordmark (mark + "Satya-Vani"
  + "सत्य वाणी"), for light backgrounds.
- `satya-vani-logo-dark.svg` / `.png` — same wordmark, for dark backgrounds.
- `satya-vani-mark-monochrome.svg` — single-color mark, for contexts that
  can't render the two-tone (teal/red) version.
- `satya-vani-mark-mono-ink.png` / `-mono-white.png` — rendered monochrome
  variants (dark-on-light, light-on-dark).
- `satya-vani-mark-showcase.html` — a static page laying out every variant
  together, for reviewing them side by side.

SVGs are the source of truth; the PNGs are rendered exports at a fixed
size for contexts that don't accept SVG.
